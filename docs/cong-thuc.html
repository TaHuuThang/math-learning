Bài 1. Đơn thức

Lũy thừa và thu gọn đơn thức

Tích hai lũy thừa cùng cơ số

xm⋅xn=xm+nx^m\cdot x^n = x^{m+n}xm⋅xn=xm+n
Kí hiệu
  • xxx: cơ số (biến)
  • m,nm, nm,n: số mũ tự nhiên
Ví dụ áp dụng

x2⋅x3=x5x^2\cdot x^3 = x^5x2⋅x3=x5; y⋅y4=y5y\cdot y^4 = y^5y⋅y4=y5.

Lũy thừa và thu gọn đơn thức

Lũy thừa của một tích

(a x)n=anxn(a\,x)^n = a^n x^n(ax)n=anxn
Kí hiệu
  • aaa: số
  • xxx: biến; nnn: số mũ tự nhiên
Ví dụ áp dụng

(−2x)2=4x2(-2x)^2 = 4x^2(−2x)2=4x2; (3y)3=27y3(3y)^3 = 27y^3(3y)3=27y3.

Lũy thừa và thu gọn đơn thức

Bậc của đơn thức

bậc(a xmynzp)=m+n+p\text{bậc}\left(a\,x^my^nz^p\right) = m + n + pbậc(axmynzp)=m+n+p
Kí hiệu
  • aaa: hệ số khác 0
  • m,n,pm, n, pm,n,p: số mũ của các biến
Điều kiện sử dụng

Đơn thức đã thu gọn, hệ số a≠0a \ne 0a=0.

Ví dụ áp dụng

−4x3y2-4x^3y^2−4x3y2 có bậc 3+2=53 + 2 = 53+2=5.

Đơn thức đồng dạng

Cộng hai đơn thức đồng dạng

a xmyn+b xmyn=(a+b) xmyna\,x^my^n + b\,x^my^n = (a + b)\,x^my^naxmyn+bxmyn=(a+b)xmyn
Kí hiệu
  • a,ba, ba,b: hệ số (khác 0)
  • xmynx^my^nxmyn: phần biến chung
Điều kiện sử dụng

Hai đơn thức phải có cùng phần biến.

Ví dụ áp dụng

3x2y+5x2y=8x2y3x^2y + 5x^2y = 8x^2y3x2y+5x2y=8x2y.

Đơn thức đồng dạng

Trừ hai đơn thức đồng dạng

Kí hiệu
  • a,ba, ba,b: hệ số (khác 0)
  • xmynx^my^nxmyn: phần biến chung
Điều kiện sử dụng

Hai đơn thức phải có cùng phần biến.

Bài 3. Phép cộng và phép trừ đa thức

Quy tắc dấu ngoặc

Bỏ ngoặc có dấu cộng

+(a−b+c)=a−b+c+(a - b + c) = a - b + c+(a−b+c)=a−b+c
Kí hiệu
  • a,b,ca, b, ca,b,c: các hạng tử
Ví dụ áp dụng

x+(2y−3)=x+2y−3x + (2y - 3) = x + 2y - 3x+(2y−3)=x+2y−3.

Quy tắc dấu ngoặc

Bỏ ngoặc có dấu trừ

−(a−b+c)=−a+b−c-(a - b + c) = -a + b - c−(a−b+c)=−a+b−c
Kí hiệu
  • a,b,ca, b, ca,b,c: các hạng tử
Ví dụ áp dụng

x−(2y−3)=x−2y+3x - (2y - 3) = x - 2y + 3x−(2y−3)=x−2y+3.

Tìm đa thức chưa biết

Tìm số hạng của tổng

M+A=B ⇒ M=B−AM + A = B \ \Rightarrow\ M = B - AM+A=B ⇒ M=B−A
Kí hiệu
  • MMM: đa thức cần tìm
  • A,BA, BA,B: đa thức đã biết
Ví dụ áp dụng

M+x=x2M + x = x^2M+x=x2 thì M=x2−xM = x^2 - xM=x2−x.

Tìm đa thức chưa biết

Tìm số bị trừ

M−A=B ⇒ M=B+AM - A = B \ \Rightarrow\ M = B + AM−A=B ⇒ M=B+A
Kí hiệu
  • MMM: đa thức cần tìm
Ví dụ áp dụng

M−x=2M - x = 2M−x=2 thì M=x+2M = x + 2M=x+2.

Tìm đa thức chưa biết

Tìm số trừ

A−M=B ⇒ M=A−BA - M = B \ \Rightarrow\ M = A - BA−M=B ⇒ M=A−B
Kí hiệu
  • MMM: đa thức cần tìm
Ví dụ áp dụng

x2−M=1x^2 - M = 1x2−M=1 thì M=x2−1M = x^2 - 1M=x2−1.

Nhân đa thức với đa thức

Bài 6. Hiệu hai bình phương. Bình phương của một tổng hay một hiệu

Ba hằng đẳng thức bậc hai

Bình phương của một tổng

(A+B)2=A2+2AB+B2(A + B)^2 = A^2 + 2AB + B^2(A+B)2=A2+2AB+B2
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
Ví dụ áp dụng

(x+5)2=x2+10x+25(x + 5)^2 = x^2 + 10x + 25(x+5)2=x2+10x+25.

Ba hằng đẳng thức bậc hai

Bình phương của một hiệu

(A−B)2=A2−2AB+B2(A - B)^2 = A^2 - 2AB + B^2(A−B)2=A2−2AB+B2
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
Ví dụ áp dụng

(3−y)2=9−6y+y2(3 - y)^2 = 9 - 6y + y^2(3−y)2=9−6y+y2.

Ba hằng đẳng thức bậc hai

Hiệu hai bình phương

A2−B2=(A−B)(A+B)A^2 - B^2 = (A - B)(A + B)A2−B2=(A−B)(A+B)
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
Ví dụ áp dụng

4x2−9=(2x−3)(2x+3)4x^2 - 9 = (2x - 3)(2x + 3)4x2−9=(2x−3)(2x+3).

Hệ quả thường dùng

Liên hệ tổng và hiệu

(A+B)2−(A−B)2=4AB(A + B)^2 - (A - B)^2 = 4AB(A+B)2−(A−B)2=4AB
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
Ví dụ áp dụng

(x+1)2−(x−1)2=4x(x + 1)^2 - (x - 1)^2 = 4x(x+1)2−(x−1)2=4x.

Hệ quả thường dùng

Tổng hai bình phương

A2+B2=(A+B)2−2ABA^2 + B^2 = (A + B)^2 - 2ABA2+B2=(A+B)2−2AB
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
Ví dụ áp dụng

Nếu a+b=5a + b = 5a+b=5, ab=6ab = 6ab=6 thì a2+b2=25−12=13a^2 + b^2 = 25 - 12 = 13a2+b2=25−12=13.

Hệ quả thường dùng

Bình phương không âm

(A±B)2+m≥m(A \pm B)^2 + m \ge m(A±B)2+m≥m
Kí hiệu
  • mmm: hằng số
Điều kiện sử dụng

Dấu "=" xảy ra khi A±B=0A \pm B = 0A±B=0.

Ví dụ áp dụng

x2+4x+7=(x+2)2+3≥3x^2 + 4x + 7 = (x + 2)^2 + 3 \ge 3x2+4x+7=(x+2)2+3≥3.

Bài 7. Lập phương của một tổng. Lập phương của một hiệu

Hằng đẳng thức bậc ba

Lập phương của một tổng

(A+B)3=A3+3A2B+3AB2+B3(A + B)^3 = A^3 + 3A^2B + 3AB^2 + B^3(A+B)3=A3+3A2B+3AB2+B3
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
Ví dụ áp dụng

(x+2)3=x3+6x2+12x+8(x + 2)^3 = x^3 + 6x^2 + 12x + 8(x+2)3=x3+6x2+12x+8.

Hằng đẳng thức bậc ba

Lập phương của một hiệu

(A−B)3=A3−3A2B+3AB2−B3(A - B)^3 = A^3 - 3A^2B + 3AB^2 - B^3(A−B)3=A3−3A2B+3AB2−B3
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
Ví dụ áp dụng

(2x−1)3=8x3−12x2+6x−1(2x - 1)^3 = 8x^3 - 12x^2 + 6x - 1(2x−1)3=8x3−12x2+6x−1.

Dạng viết gọn theo tổng (hiệu) và tích

Lập phương tổng theo tổng và tích

(A+B)3=A3+B3+3AB(A+B)(A + B)^3 = A^3 + B^3 + 3AB(A + B)(A+B)3=A3+B3+3AB(A+B)
Kí hiệu
  • A+BA + BA+B: tổng; ABABAB: tích
Ví dụ áp dụng

x+y=2x + y = 2x+y=2, xy=−3xy = -3xy=−3: x3+y3=8+18=26x^3 + y^3 = 8 + 18 = 26x3+y3=8+18=26.

Dạng viết gọn theo tổng (hiệu) và tích

Lập phương hiệu theo hiệu và tích

(A−B)3=A3−B3−3AB(A−B)(A - B)^3 = A^3 - B^3 - 3AB(A - B)(A−B)3=A3−B3−3AB(A−B)
Kí hiệu
  • A−BA - BA−B: hiệu; ABABAB: tích
Ví dụ áp dụng

a−b=1a - b = 1a−b=1, ab=6ab = 6ab=6: a3−b3=1+18=19a^3 - b^3 = 1 + 18 = 19a3−b3=1+18=19.

Bài 8. Tổng và hiệu hai lập phương

Tổng và hiệu hai lập phương

Tổng hai lập phương

Ví dụ áp dụng

x3+27=(x+3)(x2−3x+9)x^3 + 27 = (x + 3)(x^2 - 3x + 9)x3+27=(x+3)(x2−3x+9).

Tổng và hiệu hai lập phương

Hiệu hai lập phương

A3−B3=(A−B)(A2+AB+B2)A^3 - B^3 = (A - B)(A^2 + AB + B^2)A3−B3=(A−B)(A2+AB+B2)
Kí hiệu
  • A,BA, BA,B: số hoặc biểu thức
  • A2+AB+B2A^2 + AB + B^2A2+AB+B2: bình phương thiếu của tổng
Ví dụ áp dụng

x3−8=(x−2)(x2+2x+4)x^3 - 8 = (x - 2)(x^2 + 2x + 4)x3−8=(x−2)(x2+2x+4).

Liên hệ với lập phương của tổng, hiệu

Tổng hai lập phương theo tổng và tích

A3+B3=(A+B)3−3AB(A+B)A^3 + B^3 = (A + B)^3 - 3AB(A + B)A3+B3=(A+B)3−3AB(A+B)
Kí hiệu
  • A+BA + BA+B: tổng; ABABAB: tích
Ví dụ áp dụng

a+b=5a + b = 5a+b=5, ab=6ab = 6ab=6: a3+b3=125−90=35a^3 + b^3 = 125 - 90 = 35a3+b3=125−90=35.

Liên hệ với lập phương của tổng, hiệu

Hiệu hai lập phương theo hiệu và tích

A3−B3=(A−B)3+3AB(A−B)A^3 - B^3 = (A - B)^3 + 3AB(A - B)A3−B3=(A−B)3+3AB(A−B)
Kí hiệu
  • A−BA - BA−B: hiệu; ABABAB: tích
Ví dụ áp dụng

a−b=1a - b = 1a−b=1, ab=6ab = 6ab=6: a3−b3=1+18=19a^3 - b^3 = 1 + 18 = 19a3−b3=1+18=19.

Bài 9. Phân tích đa thức thành nhân tử

(x+1)2−4=(x−1)(x+3)(x + 1)^2 - 4 = (x - 1)(x + 3)(x+1)2−4=(x−1)(x+3).
